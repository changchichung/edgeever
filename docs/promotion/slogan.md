## 📢 社區推廣（如掘金、V2EX）核心賣點詞

* **三零特性**：零服務器開銷、零運維負擔、零訂閱費用。
* **白嫖配額**：每天 10 萬次免費 Workers 調用，15 萬條 D1 筆記行數，10GB 免費 R2 附件存儲。
* **AI 大腦**：原生集成 Model Context Protocol (MCP)，將你的筆記瞬間轉化爲 Agent 的外部記憶庫。
