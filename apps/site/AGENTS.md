# Agent 規則與約束 (AGENTS.md)

當 AI Agent（如 Antigravity、Claude Code、Cursor 等）在本倉庫中進行協作與開發時，請務必嚴格遵守以下規則和約束：

## 官網內容更新準則

- **一切以 monorepo 根目錄爲準**：本官網（`apps/site`）所展示的所有功能介紹、安裝部署指南、數據遷移指引以及版本日誌，**必須完全基於當前 EdgeEver 倉庫根目錄的實際代碼和文檔內容**（如根目錄 `README.md`、`docs/*`、以及組件/API 實際實現）進行提取和自動生成。
- **同步更新檢查**：在對本官網的內容、博客或特性列表進行任何修改前，AI Agent 必須優先讀取和檢查倉庫根目錄中的最新代碼和文檔更新情況，防止官網內容與項目實際版本脫節。
- **拒絕虛假/佔位信息**：嚴禁編寫任何與 `edgeever` 項目無關或不符合其實際現狀的虛構內容（包括通用的模版佔位符），確保呈現給用戶的所有技術細節都真實可靠。
- **文檔一致性**：若根目錄中有關 Cloudflare 部署協議（`docs/agent-deploy-cloudflare.md`）或遷移指南（`docs/evernote-migration-guide.md`）發生變更，官網對應的博客及文檔頁面也必須同步更新，保持嚴格的一致性。
